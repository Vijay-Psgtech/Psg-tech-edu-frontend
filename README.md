# PSG COLLEGE OF TECHNOLOGY WEBSITE - FRONTEND

This is the frontend repository for the PSG College of Technology website. It contains the code and assets necessary to build and deploy the website's user interface.

# TECH STACK
- **React**: A JavaScript library for building user interfaces.
- **Tailwind CSS**: A utility-first CSS framework for styling the website.
- **Vite**: A build tool that provides a fast development environment and optimized production builds.
- **React Router**: A library for handling routing in React applications.
